One-time setup needed

This app needs a Supabase project to store tasks. Open index.html and:

  1. Create a free project at supabase.com
  2. Run supabase-setup.sql (in this folder) in its SQL Editor
  3. Copy your Project URL and anon public key into the SUPABASE_URL / SUPABASE_ANON_KEY constants near the top of the script
